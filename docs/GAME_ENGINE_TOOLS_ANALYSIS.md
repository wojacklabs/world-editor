## 2. RPG Maker(알만툴) 핵심 기능 분석

RPG Maker는 **비프로그래머도 RPG를 만들 수 있게 해주는** 도구로, 다음 핵심 시스템들이 그 접근성을 제공합니다.

### 2-1. 이벤트 시스템 (Event System)

RPG Maker의 **가장 핵심적인 차별점**. 코딩 없이 게임 로직을 만들 수 있게 해줌.

```
이벤트 = NPC/오브젝트/트리거 포인트
├── 이벤트 페이지 (조건별 다른 동작)
│   ├── 트리거 조건 (스위치, 변수, 아이템 소지 등)
│   ├── 외형 설정 (스프라이트, 방향)
│   ├── 이동 패턴 (고정/랜덤/루트)
│   └── 이벤트 커맨드 (실행할 동작들)
│       ├── 메시지 표시
│       ├── 선택지 분기
│       ├── 조건 분기 (if/else)
│       ├── 반복
│       ├── 변수/스위치 조작
│       ├── 아이템/골드 조작
│       ├── 전투 실행
│       ├── 장소 이동
│       ├── 화면 효과 (페이드, 진동 등)
│       ├── BGM/SE 재생
│       ├── 캐릭터 이동 루트
│       ├── 타이머 조작
│       └── 스크립트 호출
├── 공통 이벤트 (Common Events) - 재사용 가능한 이벤트
└── 전투 이벤트 (Battle Events) - 전투 중 이벤트
```

### 2-2. 데이터베이스 시스템 (Database)

게임의 모든 데이터를 GUI로 관리하는 통합 시스템:

| 탭 | 관리 대상 | 설정 항목 |
|----|-----------|-----------|
| **액터** | 플레이어 캐릭터 | 이름, 클래스, 초기장비, 스프라이트, 레벨 |
| **클래스** | 직업 | 능력치 성장곡선, 스킬 학습 테이블 |
| **스킬** | 기술 | 이름, 효과, 소비MP, 애니메이션, 범위 |
| **아이템** | 소비 아이템 | 효과, 가격, 설명, 사용 범위 |
| **무기** | 무기 | 공격력, 특성, 타입 |
| **방어구** | 방어구 | 방어력, 특성, 부위 |
| **적캐릭터** | 몬스터 | 능력치, 드롭아이템, 행동패턴 |
| **적그룹** | 전투 구성 | 적 배치, 전투 이벤트 |
| **스테이트** | 상태이상 | 독, 마비, 공격력 업 등 효과 |
| **애니메이션** | 전투 애니메이션 | 프레임 단위 이미지+사운드 |
| **타일셋** | 맵 타일 | 이미지, 통행 가능 여부, 지형 태그 |
| **공통이벤트** | 재사용 이벤트 | 글로벌 실행 가능한 이벤트 로직 |
| **시스템** | 게임 설정 | 타이틀, 초기 파티, 음악, 용어 |

### 2-3. 맵 에디터

```
맵 에디터
├── 4개 레이어 (수동/자동 선택)
├── 오토타일 (A1~A5)
│   ├── A1: 애니메이션 타일 (바다, 폭포)
│   ├── A2: 지면 타일 (기본 + 데코)
│   ├── A3: 건물 타일 (벽)
│   ├── A4: 벽 타일 (던전)
│   └── A5: 일반 타일
├── 장식 타일 (B~E)
├── 그림자 펜
├── 리전 설정 (영역 지정)
├── 맵 트리 (계층 구조)
└── 맵 속성 (크기, BGM, 배경, 인카운터율)
```

### 2-4. 전투 시스템

- **프론트 뷰**: 1인칭 시점 턴제 전투 (드래곤퀘스트 스타일)
- **사이드 뷰**: 횡스크롤 전투 (파이널판타지 스타일)
- **턴 기반**: 속도 기반 행동 순서
- **Effekseer**: 파티클 기반 전투 애니메이션

### 2-5. 캐릭터 생성기

- 얼굴/머리/눈/입/코/액세서리 등 파츠 조합
- 자동 스프라이트 + 얼굴 이미지 생성
- SV(사이드뷰) 배틀러 자동 생성

### 2-6. 플러그인/스크립트 시스템

- JavaScript 기반 플러그인 (MV/MZ)
- 플러그인 매니저 (ON/OFF, 순서, 파라미터)
- 플러그인 커맨드 (이벤트에서 호출)
- 노트태그 (데이터베이스 확장)

### 2-7. 오디오 시스템

| 카테고리 | 용도 |
|----------|------|
| **BGM** | 배경음악 (루프) |
| **BGS** | 배경 효과음 (바람, 비, 군중) |
| **ME** | 팡파레 (레벨업, 퀘스트 완료) |
| **SE** | 효과음 (검 휘두르기, 문 열기) |

### 2-8. 배포

- Windows, macOS, Linux
- iOS, Android
- HTML5 (웹 브라우저)

## 4. GAP 분석: 부족한 기능 목록

현재 World Editor에 **없거나 부족한 기능**을 우선순위별로 정리합니다.

### 🔴 Critical (반드시 필요) — 게임을 "만들 수 있게" 해주는 핵심

#### 4-1. 비주얼 이벤트/로직 시스템
> RPG Maker의 이벤트 시스템 + Construct의 이벤트 시트에 해당

**현재 상태:** ❌ 없음
**필요 이유:** 코딩 없이 게임 로직을 만들 수 없으면 "게임 제작 도구"가 아닌 "맵 에디터"에 불과

**구현 범위:**
- 노드/블록 기반 비주얼 스크립팅 에디터
- 트리거 시스템 (접근, 클릭, 자동, 병렬)
- 조건 분기 (if/else/switch)
- 변수/플래그(스위치) 시스템
- 이벤트 커맨드 세트:
  - 대화 표시 (대화창 + 선택지)
  - 캐릭터 이동/회전
  - 아이템/변수 조작
  - 장면 전환 (맵 이동)
  - 화면 효과 (페이드, 셰이크 등)
  - 오디오 재생
  - 대기/타이머
  - 커스텀 스크립트 호출

#### 4-2. 캐릭터/NPC 시스템
> RPG Maker의 액터 + 이벤트 캐릭터에 해당

**현재 상태:** ❌ 없음 (프리뷰에 플레이어 캐릭터 없음)
**필요 이유:** RPG의 핵심 요소

**구현 범위:**
- 플레이어 캐릭터 (3D 모델, 3인칭/1인칭)
- NPC 배치 및 동작 패턴 (이동 루트, 대기, 순찰)
- 캐릭터 속성 (HP, MP, 레벨, 스탯)
- 장비 시스템 (무기/방어구 교체)
- 캐릭터 애니메이션 (idle, walk, run, attack)
- 대화 인터랙션 (접근 시 말풍선/대화 시작)

#### 4-3. 게임 데이터베이스 시스템
> RPG Maker의 데이터베이스에 해당

**현재 상태:** ❌ 없음
**필요 이유:** 아이템, 스킬, 적 등 게임 데이터를 체계적으로 관리하는 핵심 도구

**구현 범위:**
- GUI 기반 데이터 에디터
- 탭 구성: 캐릭터/클래스/스킬/아이템/무기/방어구/적/상태이상
- 각 엔트리별 설정 패널
- 데이터 간 참조 (예: 캐릭터→클래스→스킬 연결)
- JSON 기반 데이터 저장

#### 4-4. 대화 시스템
> RPG Maker의 메시지 표시 + 선택지 시스템에 해당

**현재 상태:** ❌ 없음
**필요 이유:** 스토리 전달의 핵심 수단

**구현 범위:**
- 대화창 UI (이름, 얼굴 아이콘, 텍스트)
- 타이핑 효과 (글자 단위 표시)
- 선택지 분기
- 대화 트리 에디터 (노드 그래프 또는 리스트)
- 변수/조건에 따른 동적 텍스트
- 대화 로그/히스토리

#### 4-5. 오디오 시스템
> RPG Maker의 BGM/BGS/ME/SE에 해당

**현재 상태:** ❌ 없음 (날씨 시각 효과는 있으나 사운드 없음)
**필요 이유:** 게임 몰입감의 필수 요소

**구현 범위:**
- BGM 재생/정지/페이드 (Web Audio API)
- 효과음 재생 (SE)

### 결론

**World Editor는 "월드 빌딩/맵 에디터"로서 매우 강력하지만, "게임 제작 도구"가 되려면 게임 로직, 캐릭터, 대화, 데이터 관리, 오디오 등의 핵심 시스템이 추가되어야 합니다.**

가장 시급한 것은 **비주얼 이벤트/스크립팅 시스템**입니다. 이것이 있어야 사용자가 코딩 없이 게임 로직을 만들 수 있으며, 이는 RPG Maker가 20년간 성공할 수 있었던 가장 큰 이유이기도 합니다.

현재 기술 스택(React + Three.js + Zustand)은 이러한 기능들을 구현하기에 충분히 적합하며, 특히 React Flow를 활용한 비주얼 스크립팅, Web Audio API를 활용한 오디오, Three.js AnimationMixer를 활용한 캐릭터 애니메이션 등은 자연스럽게 기존 아키텍처에 통합될 수 있습니다.
